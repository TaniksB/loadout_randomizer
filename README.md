# Destiny 2 Loadout Randomizer (updated for Season 28)

Randomizes the following:  
-Classes  
-Exotic Armors  
-Subclasses  
-Aspects  
-Supers  
-Legendary Weapon Types and Exotics for all 3 Weapon Slots  

### The randomizer ensures that Exotic Armors only appear with their paired abilites or weapons, if they would be useless otherwise. For example:  

Osmiomancy Gloves ensure that a Stasis or Prismatic Subclass is rolled, as the Exotic does nothing without access to Coldsnap Grenades.  
_Your Coldsnap grenades have an additional charge that recharges quicker on hits. The seeker spawned from Coldsnap grenades travels farther._  

Rain of Fire still provides a partial benefit without a Fusion or LFR, so it can appear alongside any weapons.  
_Air dodge reloads all of your weapons and improves the airborne effectiveness of Fusion Rifles and Linear Fusion Rifles; final blows with these weapons make you radiant. Provides a moderate benefit to the airborne effectiveness stat of Fusion Rifles and Linear Fusion Rifles._  

## How to use:  

Run main.py from a terminal. Make sure that you have Python 3 installed.
